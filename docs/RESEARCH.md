# Qwen Image 3.0 research note

## Positioning

Qwen Image 3.0 is the third-generation image generation and editing model announced by the Qwen team on July 21, 2026. The official launch groups its goals under three labels: Rich Content, Authentic Details, and Deep Knowledge. Qwen reports support for instructions up to 4.5K tokens, text down to 10 pixels, native rendering across 12 languages, more than 100 artistic styles, dense publications, nested interfaces, photorealistic texture, and reference-guided editing.

These are first-party capability statements, not independent benchmark findings. The launch post does not publish model weights, architecture, API parameters, pricing, or a technical report for Qwen Image 3.0, so this repository does not infer those details from earlier Qwen Image releases.

## Curation method

The initial collection was researched on 2026-07-21 from Qwen's public article API and canonical launch page. Twelve official showcase concepts were selected across long-form information design, typography, interface generation, photorealism, and reference editing. The launch article publishes results and capability descriptions but not complete source prompts. Each prompt in this repository is therefore an original English production reconstruction that preserves the showcased task, official result media, canonical source, and adaptation status without pretending to be verbatim source text.

Launch-day community discussion was reviewed separately. Posts that repeated the announcement or shared images without a complete reusable prompt were excluded. Community cases should be added only when the original post identifies Qwen Image 3.0, exposes inspectable result media, and contains enough prompt detail to reproduce the workflow.
