# Contributing to the Qwen Image 3.0 collection

Submit a case only when the canonical source explicitly identifies Qwen Image 3.0, contains a reusable prompt, attributes the creator, and exposes inspectable image result media.

## Review gates

1. Provenance: preserve the canonical post and creator.
2. Prompt completeness: include enough direction to reproduce the production logic.
3. Model evidence: the source must name Qwen Image 3.0; inference from Qwen Image 2.0 or earlier releases is not accepted.
4. Media evidence: the result must be inspectable without a private login.
5. Originality: duplicate sources, prompts, and media are rejected.
6. Editorial value: the case must teach a transferable workflow rather than promote a tool.
7. Claim boundary: architecture, weights, benchmarks, API details, and pricing require a Qwen Image 3.0 primary source.
